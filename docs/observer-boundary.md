# Authority Boundary

Recognition ≠ Qualification Authority ≠ Execution Authority.

Generated output is informational. It contains no approval, denial, recommendation, prioritization, hold, validity verdict, authority mutation, reassessment requirement, continuation instruction, pacing instruction, or execution instruction.

The implementation also preserves epistemic boundaries: observed context is not complete operational reality, reference lineage is not verified provenance, and a configured equality result does not determine broader operational meaning.
