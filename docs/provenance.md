# Reference Lineage and Provenance Boundary

RecognitionResults retain references to supplied facts, source records, selectors, profile and rule versions, values, and the comparison outcome. This makes the configured derivation reconstructable from repository artifacts.

These are reference-lineage links. The implementation does not authenticate source systems, verify source records, establish source truth, or provide cryptographic provenance.

The public implementation is separate from private evaluation work and makes no claim about private results.
